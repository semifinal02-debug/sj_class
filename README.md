# BuildBrief Lite — 건설산업 뉴스 트렌드

교수님 과제: 건설 뉴스 트렌드를 API 키 없이 수집·분석하는 Next.js 웹사이트입니다.

- Google 뉴스 공개 RSS(국내 건설·건축, 해외 건설)를 서버에서 수집합니다.
- 최근 7일 수집 기사 제목에 등장한 10개 건설 키워드의 언급량으로 순위를 계산합니다.
- 키워드별 일자별 언급량 그래프, 국내 5건·해외 2건, 분야별 필터·검색을 제공합니다.
- 해당 순위는 **수집된 RSS 기사의 키워드 언급량**이며 실제 검색량·전체 언론 보도량이 아닙니다.

실행: Node.js 20.9 이상에서 `npm install` 후 `npm run dev`. API 키나 환경변수는 필요 없습니다.

배포: Vercel에서 이 GitHub 저장소를 Import해 Next.js 프로젝트로 배포합니다. 별도 환경변수는 없습니다.
